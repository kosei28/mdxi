# mdxi へようこそ

このページは MDX で書かれたドキュメントです。入力された答えに合わせて、表示される内容が動的に切り替わります。入力した内容は、このファイル（`docs/welcome.mdx`）のフロントマターの `values` に自動で保存されます。`status` は、このドキュメントの状態を表すラベルです。ラベルの項目は `vite.config.ts` で定義できます。

## チームランチのお知らせ

  ]}
